استيراد أسئلة PDF

يستخرج المحتوى النصي من ملف PDF، ويعزل المقدمات والعناوين التمهيدية والأسئلة المقالية، ويحلل أسئلة الاختيار من متعدد (A / B / C / D...) لتحديد الخيار الملوّن أو المظلل عبر طبقات فحص متعددة.
ملاحظة جودة وتصحيح: أي سؤال لا يحقق إشارة تمييز واضحة أو تتعدد فيه الخيارات الملوّنة يُعلَّم تلقائياً للمراجعة اليدوية قبل الاعتماد أو الإرسال.
